# skills

[English](README.md) | [简体中文](README.zh-CN.md)

This repo contains personal skills in the [Agent Skills](https://agentskills.io/specification) format.

## Installation

Install all skills:

```bash
npx skills add itzLan1126/skills
```

### Skills List

| Skill                                      | Description                                                                                             | Install                                               |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| [`close-pr`](skills/close-pr/SKILL.md)     | Clean up local and remote branches and switch back to the default branch after a PR is merged or closed | `npx skills add itzLan1126/skills --skill close-pr`   |
| [`git-commit`](skills/git-commit/SKILL.md) | Inspect Git changes, organize logical commits, and write Conventional Commits messages                  | `npx skills add itzLan1126/skills --skill git-commit` |
